# 项目技术细节

## ESP32-S3 N16R8 硬件能力检查

### 确认可用的硬件资源
- **CPU**: Xtensa LX7双核 @ 240MHz
- **Flash**: 16MB (Quad SPI)
- **PSRAM**: 8MB (Octal SPI, OPIO)
- **USB OTG**: 支持TinyUSB设备模式
- **USB Serial/JTAG**: 内置独立USB串口控制器（不占用OTG）
- **UART**: 3路（UART0=console, UART1=其他协议, UART2=MIDI）
- **GPIO**: 多个可用，MIDI默认TX=GPIO1, RX=GPIO2

### 安全注意事项
- MIDI默认使用GPIO1(TX)和GPIO2(RX)，可通过`config`命令修改
- USB MIDI设备模式不与内置USB Serial/JTAG冲突
- API端口72/73仅在WiFi连接成功后可用
- 单IP并发限制防止资源耗尽
- 避免在MIDI活动期间进行OTA更新
- 使用前请确保5-Pin DIN MIDI接口有合适的电平转换电路（3.3V逻辑电平）

## 依赖
- ESP32 Arduino Core (pioarduino/platform-espressif32)
- TinyUSB with MIDI support (CONFIG_TINYUSB_MIDI_ENABLED)
- ESP-IDF HTTP Server (esp_http_server)
- ArduinoJson >= 7.3.0

## API端点

### 端口72 (HTTP REST)

#### GET /info
返回设备信息和MIDI状态。

#### GET /status
返回当前MIDI运行状态。

#### POST /send
发送MIDI消息。支持格式：
- `{"note":{"channel":1,"note":60,"velocity":100}}` — Note On
- `{"cc":{"channel":1,"controller":7,"value":100}}` — Control Change
- `{"program":{"channel":1,"program":0}}` — Program Change
- `{"pitch":{"channel":1,"value":8192}}` — Pitch Bend
- `{"raw":[0x90,0x3C,0x7F]}` — 原始字节
- `{"sysex":[0x7E,0x7F,0x09,0x01]}` — SysEx
- `{"clock":true}` — 时钟
- `{"transport":"start|stop|continue"}` — 传输控制

### 端口73 (WebSocket)
- 端点: `/midi`
- 双向通信
- 发送JSON格式MIDI命令到设备（同REST API格式）
- 接收JSON格式MIDI消息（包含timestamp, status, channel, data1, data2, display）
