# 项目技术细节

## 架构

### 设计模式
- 依赖注入（DependencyProvider）
- 命令模式（ActionDispatcher + Controller）
- 全局状态管理（GlobalState）
- 单例服务模式

### 目录结构
```
src/
├── Controllers/     - 命令处理器（MidiController, GpioController 等）
├── Dispatchers/     - 动作分发器（ActionDispatcher）
├── Enums/           - 枚举定义（ModeEnum）
├── Providers/       - 依赖注入（DependencyProvider）
├── Services/        - 核心服务（MidiService, MidiApiService）
├── Shells/          - 终端/Web 界面处理器（HelpShell, WebShell）
└── States/          - 全局状态（GlobalState）
```

## MIDI 实现

### MidiService (UART)
- 使用 Arduino HardwareSerial (Serial2)
- 引脚：TX=17, RX=18
- 波特率：31250 8N1
- 支持：所有 MIDI 消息类型（Note On/Off, CC, PC, PitchBend, SysEx, 实时消息）
- Running Status 协议支持
- SysEx 消息 (0xF0-0xF7) 支持

### MidiApiService (WiFi)
- HTTP REST API（端口 72）
  - GET /info - 设备信息
  - POST /send - 发送 MIDI 消息
  - WebSocket /midi - 双向 MIDI 流
- WebSocket（端口 73）- MIDI 流转发
- 单 IP 并发限制
- 黑白名单访问控制
- 开机自启动选项

### API 消息格式
```json
// Note
{"note":{"channel":1,"note":60,"velocity":100}}
// CC
{"cc":{"channel":1,"controller":7,"value":100}}
// Program Change
{"program":{"channel":1,"program":0}}
// Pitch Bend
{"pitch":{"channel":1,"value":8192}}
// Raw MIDI bytes
{"raw":[144,60,127]}
// SysEx
{"sysex":[126,127,9,1]}
// Clock Start/Stop
{"clock":true} 或 {"transport":"start|stop|continue"}
```
