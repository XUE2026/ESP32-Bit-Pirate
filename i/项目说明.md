# 项目说明

## 概述
此项目为 ESP32 Bit Pirate 的分支，专注于为 ESP32-S3 N16R8 硬件添加完整的 MIDI 支持。

## 硬件目标
- **ESP32-S3 N16R8**（16MB Flash，8MB PSRAM）
- 其他硬件未经测试，不保证兼容

## MIDI 架构
项目提供三层 MIDI 能力：

### 1. UART MIDI（5-Pin DIN）
- 基于ESP32 UART2硬件
- 31250 baud 8N1 标准MIDI速率
- 支持完整MIDI消息：Note On/Off, CC, PC, PitchBend, SysEx, 实时消息
- 支持Running Status解析
- 支持MIDI Thru（RX回显到TX）

### 2. USB MIDI设备类
- 通过ESP32-S3原生USB Type-C口暴露为USB MIDI设备
- 基于TinyUSB实现
- 需要CONFIG_TINYUSB_MIDI_ENABLED构建标志
- 连接电脑后可被DAW/音乐软件识别为MIDI设备

### 3. WiFi MIDI API
- 端口72: HTTP REST API（JSON格式）
- 端口73: WebSocket双向MIDI流
- 支持设备信息查询、MIDI消息发送、实时MIDI流监听
- 单IP并发限制
- 黑白名单访问控制
- WiFi连接自动启动

## 安全
- API默认开机自启动
- 通过黑白名单控制访问
- 单客户端并发限制
