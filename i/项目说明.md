# 项目说明

## ESP32 Bit Pirate

一个基于 ESP32-S3 N16R8 的多功能工具项目。

### 硬件目标
- **型号**: ESP32-S3 N16R8
- **CPU**: XTensa LX7 双核 @ 240MHz
- **Flash**: 16MB
- **PSRAM**: 8MB
- **USB**: 支持 USB OTG (TinyUSB)、USB Serial/JTAG
- **UART**: 3 路 UART（UART0 调试，UART1/2 可用）

### 核心功能
1. **GPIO 控制模式** - GPIO 读写、PWM、ADC、I2C、SPI
2. **WiFi 工具模式** - WiFi 扫描、连接、HTTP 客户端/服务器
3. **MIDI 模式** - UART MIDI + USB MIDI + WiFi MIDI API
   - 5-Pin DIN (UART2, 31250 baud) MIDI 输入/输出
   - WiFi API 端口 72 (HTTP REST) + 端口 73 (WebSocket)
   - 单 IP 并发限制
   - 黑白名单访问控制
4. **终端/Web 控制** - 串口终端 + Web:80 管理界面

### 构建环境
- PlatformIO (Arduino 框架)
- 环境：s3-devkit-n16-r8
