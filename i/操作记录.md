# 操作记录

## 2026-06-26 MIDI 支持完整实现

### 新增功能
1. **UART MIDI（5-Pin DIN）** — 基于ESP32 UART2，31250 baud 8N1标准MIDI速率
2. **USB MIDI设备类** — 通过TinyUSB暴露为USB MIDI设备（CONFIG_TINYUSB_MIDI_ENABLED）
3. **WiFi MIDI API** — 端口72 HTTP REST API + 端口73 WebSocket双向流
4. **单IP并发限制** — 最多1个客户端同时使用API
5. **黑白名单访问控制** — 终端可配置白名单/黑名单IP
6. **WiFi自启动** — WiFi连接成功后自动启动MIDI API服务
7. **终端完整命令集** — config/send/receive/sniff/note/cc/pgm/pitch/clock/thru/usb/api/reset
