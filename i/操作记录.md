# 操作记录

## 2026-06-28 修复 USB MIDI 相关问题

### 问题1: api start 命令不存在
**原因**: AutoCompleteWords.h 中缺少 "api"，导致 TerminalCommandTransformer::autoCorrectRoot() 把 "api" 自动纠正为 "ap"（WiFi的ap命令）
**修复**: 在 AutoCompleteWords.h 通用命令区域添加 "api" 和 "usbx"

### 问题2: midi 模式的 usb 命令与全局模式切换命令冲突
**原因**: 输入 "usb" 会被 autoCorrectRoot 纠正为 "USB" 模式切换
**修复**: 将 midi 模式的 usb 命令改为 usbx（usbx 不在 autoCorrectRoot 的匹配范围内）

### 问题3: MidiService 缺少 sendMidi() 方法
**原因**: ActionDispatcher::run() 中调用 midiService.sendMidi(usbMsg)，但 MidiService 没有此方法
**修复**: 添加 MidiService::sendMidi(const MidiMessage&) 方法

### 问题4: ActionDispatcher 中 USB MIDI 轮询代码
**修复**: 恢复 ActionDispatcher::run() 中的 USB MIDI 后台轮询逻辑

### 问题5: DependencyProvider 缺少 USBMidiService
**修复**: 
- 在 DependencyProvider.h 添加 #include "Services/USBMidiService.h"
- 添加 USBMidiService& getUsbMidiService()
- 添加 USBMidiService usbMidiService 成员
- 在 DependencyProvider.cpp 初始化列表中添加 usbMidiService()
- MidiController 构造函数添加 usbMidiService 参数
